# Дадлага.мн

Их, дээд сургуулийн оюутан үйлдвэрлэлийн дадлагын газраа олох, байгууллага оюутан сонгох веб систем.

Оюутны үйлдвэрлэлийн дадлагын хүрээнд хийсэн төсөл.

---

## Юу хийдэг вэ

**Оюутны тал**
- Бүртгүүлж нэвтэрнэ
- Байгууллагуудыг хайх, чиглэл болон байршлаар шүүх
- Дадлагын чиглэлд хүсэлт илгээх
- Хүсэлт бүрийн явцыг хянах

**Байгууллагын тал**
- Дадлагын чиглэл, авах оюутны тоог зарлах
- Ирсэн хүсэлтийг харах, хүлээн авах
- Оюутантай холбогдсоны дараа эцсийн шийдвэрээ тэмдэглэх

Хүсэлтийн төлөв: `Илгээсэн` → `Хүлээн авсан` → `Тэнцсэн` / `Тэнцээгүй`

Байгууллага оюутантай холбогдох нь системээс гадуур явагдана — систем нь зөвхөн танилцуулж, шийдвэрийг бүртгэнэ.

## Технологи

| Давхарга | Хэрэгсэл |
|---|---|
| Frontend | Vanilla JS (ES modules), CSS, SPA hash router |
| Backend | Node.js, Express |

Framework ашиглаагүй — бүх компонент гараар бичигдсэн.

## Суулгах

### Шаардлага

- Node.js 18+
- MySQL 8.0+

### 1. Кодыг татах

```bash
git clone https://github.com/<хэрэглэгч>/dadlaga.git
cd dadlaga
```

### 2. Өгөгдлийн сан үүсгэх

MySQL Workbench эсвэл терминалаар:

```bash
mysql -u root -p < db/schema.sql
mysql -u root -p < db/seed.sql     # туршилтын өгөгдөл, сонголтоор
```

`schema.sql` нь байгаа санг **устгаад** шинээр үүсгэнэ.

### 3. Тохиргоо

```bash
cd server
cp .env.example .env
```

`.env` файлаа нээж бөглөнө:

```dotenv
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD="таны нууц үг"
DB_NAME=internship_system

PORT=3000
BASE_URL=http://localhost:3000
JWT_SECRET=

SHOW_RESET_LINK=true
```

`JWT_SECRET`-ийг үүсгэх:

```bash
npm install
npm run gen-secret
```

Гарсан утгыг `.env`-д хуулна. Дор хаяж 32 тэмдэгт байх ёстой — эс бөгөөс сервер асахгүй.

### 4. Ажиллуулах

```bash
npm start
```

Браузераар → **http://localhost:3000**

Холболт шалгах:

```bash
npm run test-db
```

## Туршилтын бүртгэл

`db/seed.sql` ажиллуулсан бол. Бүх нууц үг: `123456`

| Дүр | Нэвтрэх нэр |
|---|---|
| Оюутан | `temuulen`, `saraa`, `bilguun`, `anuujin`, `zolboo` |
| Байгууллага | `itzone`, `golomt`, `khanbank`, `unitel` |

`temuulen` дээр гурван өөр төлөвтэй хүсэлт байгаа тул профайл хуудсыг харахад тохиромжтой.
`itzone` дээр хамгийн олон хүсэлт ирсэн.

## Аюулгүй байдал

- Нууц үг bcrypt-ээр hash хийгдэнэ
- JWT токен, дүрийн эрх серверт шалгагдана
- Content Security Policy, HTTP хамгаалалтын толгойнууд
- Тохиргоо дутуу бол сервер асахгүй (`config.js`)
- Хэрэглэгчийн текст HTML-д орохоос өмнө цэвэрлэгдэнэ (`html` шошго)

Бодит орчинд байршуулах бол `deploy/README.md` үзнэ үү — HTTPS, хязгаарлагдмал MySQL хэрэглэгч, certbot.

**Хараахан хийгээгүй:** нэвтрэх оролдлого хязгаарлах, и-мэйл илгээх, автомат нөөцлөлт.
