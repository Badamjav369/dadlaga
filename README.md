# Дадлага.мн

Оюутнууд дадлагын байгууллагаа **өөрсдөө сонгох** боломжийг бүрдүүлсэн веб систем.

Одоогоор ихэнх оюутан үйлдвэрлэлийн дадлага хийх байгууллагаа сургуулийн хуваарилалтаар эсвэл танил талаараа дамжуулан олдог. Энэхүү систем нь оюутан бүрд системд бүртгэлтэй байгууллагуудыг харах, мэргэжлийн чиглэлдээ тохирох байгууллагыг сонгох, тухайн байгууллагад шууд хүсэлт илгээх боломжийг олгоно.

Байгууллагын хувьд мөн адил давуу талтай. Байгууллага нь ямар чиглэлээр хэдэн оюутан дадлагажуулах талаарх мэдээллээ зарлаж, ирүүлсэн хүсэлтүүдээс өөрт тохирох оюутныг сонгох боломжтой.

Энэхүү систем нь оюутны үйлдвэрлэлийн дадлагын хүрээнд боловсруулсан төсөл болно.

---

## Гол боломжууд

### Оюутан

- Байгууллагуудыг дадлагын чиглэл болон байршлаар нь шүүж, хайх
- Дадлагын чиглэл тус бүрийн сул орон тооны мэдээллийг харах
- Дадлага хийх хүсэлт илгээж, хүсэлтийн явцыг хянах

### Байгууллага

- Дадлагын чиглэл болон хүлээн авах оюутны тоог зарлах
- Ирүүлсэн хүсэлтүүдийг оюутны мэргэжил, ангийн мэдээллийн хамт харах
- Оюутны хүсэлтийг хүлээн авч, эцсийн шийдвэрийг тэмдэглэх

### Хүсэлтийн төлөв

`Илгээсэн` → `Хүлээн авсан` → `Тэнцсэн` / `Тэнцээгүй`

Байгууллага оюутантай и-мэйл болон утсаар холбогдох нь системээс гадуур явагдана.
