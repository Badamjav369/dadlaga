# Дадлага.мн

Оюутан дадлагын газраа **ёонгодог** веб систем.

Одоо ихэнх оюутан дадлагын газраа сургуулийн хуваарилалтаар, эсвэл танил
талаараа олдог. Энэ систем оюутан бүрд бүртгэлтэй байгууллагуудыг харж,
мэргэжилдээ тохирохыг нь сонгож, шууд хүсэлт илгээх боломж өгнө.

Байгууллагын хувьд ч ашигтай — ямар чиглэлээр хэдэн оюутан авахаа зарлаад,
ирсэн хүсэлтээс өөрт тохирохыг нь сонгоно.

Оюутны үйлдвэрлэлийн дадлагын хүрээнд хийсэн төсөл.

---

## Гол боломжууд

**Оюутан**
- Байгууллагуудыг чиглэл, байршлаар шүүж хайх
- Дадлагын чиглэл бүрийн сул орон тоог харах
- Хүсэлт илгээж, явцыг нь хянах

**Байгууллага**
- Дадлагын чиглэл, авах оюутны тоог зарлах
- Ирсэн хүсэлтийг оюутны мэргэжил, ангитай нь харах
- Хүлээн авах, эцсийн шийдвэрээ тэмдэглэх

Төлөв: `Илгээсэн` → `Хүлээн авсан` → `Тэнцсэн` / `Тэнцээгүй`

Байгууллага оюутантай и-мэйл, утсаар холбогдох нь системээс гадуур явагдана.

## Технологи

Node.js · Express · MySQL 8 · Vanilla JS (SPA) · JWT · bcrypt

---

## Ажиллуулах

```bash
mysql -u root -p < db/schema.sql
mysql -u root -p < db/seed.sql

cd server
npm install
cp .env.example .env      # утгуудаа бөглөх
npm run gen-secret        # JWT_SECRET үүсгэх
npm start
```

→ http://localhost:3000

**Туршилтын бүртгэл** (нууц үг `123456`)
Оюутан: `temuulen` · Байгууллага: `itzone`
